# Dependências e licenças

O código da aplicação foi refatorado a partir do HTML fornecido. Nenhuma mudança de licença ou titularidade sobre o projeto original é presumida.

O frontend distribuído utiliza React e ReactDOM (MIT), com avisos em `licencas/React.txt` e `licencas/ReactDOM.txt`. As famílias Space Grotesk, IBM Plex Sans e IBM Plex Mono são distribuídas com seus avisos SIL Open Font License na mesma pasta.

Os ícones SVG locais foram conservados do HTML recebido, que os descreve como um conjunto no estilo do Lucide. Não foi adicionada uma dependência de ícones nem foram substituídos os desenhos.

As demais dependências e versões estão em `package-lock.json`. Após `npm ci`, seus avisos de licença acompanham os respectivos pacotes em `node_modules`.
